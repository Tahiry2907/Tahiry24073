📚 Commencer le cours

📌 1. Qu'est-ce que la programmation ?

📌 1. Inona ny programmation ?

La programmation est l'activité qui consiste à écrire des instructions qu'un ordinateur peut comprendre et exécuter.

Ny programmation dia asa fanoratana toromarika izay azon'ny ordinateur takarina sy tanterahiny.

Exemple : Ohatra :

Lorsqu'une application calcule 10 + 20, le programme contient des instructions permettant d'effectuer ce calcul.

Rehefa manao calcul 10 + 20 ny application iray, dia misy toromarika ao amin'ilay programme manao izany kajy izany.

📌 2. Algorithme et programmation

📌 2. Algorithme sy programmation

Avant d'écrire un programme, on peut préparer un algorithme. Un algorithme décrit les étapes nécessaires pour résoudre un problème.

Alohan'ny hanoratana programme dia afaka manomana algorithme isika. Ny algorithme dia mamaritra ireo dingana ilaina hamahana olana iray.

Début Lire A Lire B S = A + B Afficher S Fin

Ici, le programme demande deux nombres, les additionne, puis affiche le résultat.

Eto dia maka isa roa ilay programme, manampy azy, ary mampiseho ny valiny.

📌 3. Entrée → Traitement → Sortie

📌 3. Fidirana → Fikarakarana → Vokatra

ENTRÉE → TRAITEMENT → SORTIE

Entrée : données fournies au programme.

Fidirana : angona omena ny programme.

Traitement : opérations réalisées par le programme.

Fikarakarana : asa ataon'ny programme amin'ireo angona.

Sortie : résultat produit.

Vokatra : valiny avoakan'ny programme.

📌 5. HTML, CSS et JavaScript

📌 5. HTML, CSS ary JavaScript

HTML, CSS et JavaScript sont souvent utilisés ensemble pour créer des sites Web.

HTML, CSS ary JavaScript dia matetika ampiasaina miaraka amin'ny famoronana site Web.

HTML Structure
CSS Design
JavaScript Interaction

HTML structure la page, CSS contrôle son apparence et JavaScript permet d'ajouter des comportements interactifs.

HTML no mandamina ny pejy, CSS no manamboatra ny endriny, ary JavaScript no manampy interaction.

📌 6. Langages bas niveau et haut niveau

📌 6. Langage bas niveau sy haut niveau

Langage bas niveau

Langage bas niveau

Il est proche du fonctionnement matériel de l'ordinateur. Le langage machine et l'assembleur sont des exemples.

Akaiky kokoa amin'ny fonctionnement an'ny matériel ao amin'ny ordinateur izy. Ohatra ny langage machine sy assembleur.

Langage haut niveau

Langage haut niveau

Il est généralement plus facile à lire et à écrire pour l'être humain. Python, JavaScript et Java en sont des exemples.

Mora kokoa vakiana sy soratana ho an'ny olona izy. Ohatra: Python, JavaScript ary Java.

📌 7. Compilateur et interpréteur

📌 7. Compilateur sy interpréteur

Un compilateur transforme généralement le code source en une forme exécutable avant son exécution.

Ny compilateur dia manova ny code source ho endrika azo tanterahina alohan'ny execution.

Un interpréteur exécute le programme en utilisant une étape d'interprétation pendant l'exécution.

Ny interpréteur kosa dia mandika sy manatanteraka ny programme mandritra ny execution.

⚠️ Les langages ont des modèles d'exécution différents. ⚠️ Samy manana fomba execution mety tsy hitovy ny langage.

📌 8. Les variables

📌 8. Variable

Une variable est un espace nommé permettant de stocker une valeur utilisée par un programme.

Ny variable dia toerana nomena anarana itehirizana valeur ampiasain'ny programme.

age = 18 nom = "Tahiry" prix = 2500

📌 10. Les opérateurs

📌 10. Opérateurs

a + b a - b a * b a / b a % b

Ils permettent d'effectuer des opérations mathématiques ou logiques.

Ireo no ampiasaina hanaovana calcul na opération logique.

📌 11. Les conditions

📌 11. Condition

Une condition permet au programme de prendre une décision.

Ny condition dia ahafahan'ny programme mandray fanapahan-kevitra.

age = 20 if age >= 18: print("Adulte") else: print("Mineur")

📌 12. Les boucles

📌 12. Boucle

Une boucle permet de répéter une ou plusieurs instructions.

Ny boucle dia mamela ny programme hamerina instruction iray na maromaro.

for i in range(1, 6): print(i)

📌 13. Les fonctions

📌 13. Fonction

Une fonction est un bloc de code conçu pour réaliser une tâche précise.

Ny fonction dia bloc de code natao hanao asa manokana.

def saluer(): print("Bonjour") saluer()

📌 14. Les tableaux / listes

📌 14. Tableau / Liste

noms = [ "Jean", "Marie", "Paul" ] print(noms[0])

Une liste permet de stocker plusieurs valeurs dans une même structure.

Ny liste dia ahafahana mitahiry valeur maromaro ao anaty structure iray.

📌 15. Entrée et sortie

📌 15. Fidirana sy vokatra

nom = input("Votre nom : ") print("Bonjour " + nom)

Le programme demande une information à l'utilisateur, puis affiche un résultat.

Mangataka information amin'ny utilisateur ilay programme, avy eo mampiseho valiny.

🐞 16. Les erreurs et le debugging

🐞 16. Erreur sy debugging

Lorsqu'un programme ne fonctionne pas comme prévu, le programmeur recherche l'erreur et la corrige. Cette opération est appelée debugging.

Rehefa tsy mandeha araka ny tokony ho izy ny programme, dia mitady ny erreur ny programmeur ary manitsy izany. Izany no atao hoe debugging.

Exemple : une parenthèse oubliée peut provoquer une erreur. Ohatra : mety hiteraka erreur ny parenthèse adino.

🔐 18. Programmation et sécurité

🔐 18. Programmation sy sécurité

Un programme doit être conçu en tenant compte de la sécurité. Il faut notamment valider les données reçues, protéger les informations sensibles et éviter les erreurs dangereuses.

Tokony hojerena ihany koa ny sécurité rehefa manao programme. Tokony hojerena ny données miditra, harovana ny information manokana ary ialana ny erreur mety hampidi-doza.

🤖 19. Programmation et intelligence artificielle

🤖 19. Programmation sy intelligence artificielle

La programmation est utilisée pour développer de nombreux systèmes d'intelligence artificielle.

Ny programmation dia ampiasaina amin'ny famoronana rafitra maro mifandray amin'ny intelligence artificielle.

Exemple : Python est très utilisé dans l'IA et la science des données. Ohatra : Python dia tena ampiasaina amin'ny IA sy data science.

🚀 20. Mini-projet

🚀 20. Mini-projet

Créer un programme qui demande le nom et l'âge d'un utilisateur et affiche un message différent selon son âge.

Mamorona programme mangataka anarana sy taona, ary mampiseho message miova arakaraka ny taona.

nom = input("Nom : ") age = int(input("Age : ")) if age >= 18: print("Bonjour " + nom) print("Vous êtes majeur.") else: print("Bonjour " + nom) print("Vous êtes mineur.")
