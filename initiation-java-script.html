📌 1. Qu'est-ce que JavaScript ? 1. Inona ny JavaScript ?

JavaScript est un langage de programmation utilisé principalement pour rendre les pages web interactives.

JavaScript dia fiteny programmation ampiasaina indrindra mba hahatonga ny pejy web hifandray sy hifampiresaka amin'ny mpampiasa.

HTML + CSS + JavaScript HTML + CSS + JavaScript

HTML = structure
CSS = apparence
JavaScript = comportement et interaction HTML = firafitra
CSS = endrika
JavaScript = fihetsika sy interaction

📌 2. Premier programme 2. Programme voalohany

JavaScript peut afficher un message avec console.log().

JavaScript dia afaka mampiseho hafatra amin'ny console.log().

console.log("Bonjour !");

📦 3. Les variables 3. Ny variables

Une variable permet de stocker une information.

Ny variable dia toerana itehirizana information iray.

let nom = "Jean"; let age = 20; console.log(nom); console.log(age);

let / const / var

Mot Utilisation
let Variable modifiable
const Valeur constante
var Ancienne manière

🔀 6. Les conditions 6. Ny conditions

Une condition permet de prendre une décision.

Ny condition dia ahafahan'ny programme mandray fanapahan-kevitra.

let age = 20; if(age >= 18){ console.log("Adulte"); }else{ console.log("Mineur"); }

🔁 7. Les boucles 7. Ny boucles

Une boucle permet de répéter une instruction.

Ny boucle dia ahafahana mamerina instruction imbetsaka.

for(let i = 0; i < 5; i++){ console.log(i); }

Résultat : 0, 1, 2, 3, 4

Vokatra : 0, 1, 2, 3, 4

⚙️ 8. Les fonctions 8. Ny fonctions

Une fonction regroupe des instructions que l'on peut réutiliser.

Ny fonction dia manangona instructions izay azo ampiasaina imbetsaka.

function saluer(){ console.log("Bonjour"); } saluer();

Avec paramètre

function addition(a,b){ return a + b; } console.log(addition(5,3));

📚 9. Les tableaux (Array) 9. Ny tableaux (Array)

Un tableau permet de stocker plusieurs valeurs.

Ny tableau dia ahafahana mitahiry valeurs maro.

let fruits = [ "Pomme", "Banane", "Orange" ]; console.log(fruits[0]);

Le premier élément possède l'indice 0.

Ny élément voalohany dia manana indice 0.

🧩 10. Les objets 10. Ny objets

let eleve = { nom: "Jean", age: 15, classe: "3ème" }; console.log(eleve.nom);

Un objet regroupe plusieurs informations concernant une même chose.

Ny objet dia manangona informations maromaro momba zavatra iray.

🌐 11. Le DOM 11. Ny DOM

Le DOM permet à JavaScript de modifier les éléments HTML.

Ny DOM dia ahafahan'ny JavaScript manova ireo éléments HTML.

document.getElementById("titre").innerHTML = "Bonjour !";

🧠 15. Exemple complet 15. Ohatra feno

let nom = "Tahiry"; let age = 20; if(age >= 18){ console.log( nom + " est adulte" ); }else{ console.log( nom + " est mineur" ); }

Ici, JavaScript utilise une variable et une condition pour afficher un résultat.

Eto dia mampiasa variable sy condition ny JavaScript mba hamoahana résultat.
