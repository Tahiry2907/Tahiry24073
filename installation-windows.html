Installation Windows 10 / 11 PRO++

Guide pratique d'installation et de dépannage

🎯 Objectif de cette leçon

Apprendre à préparer l'installation de Windows, démarrer depuis une clé USB, comprendre les étapes de l'installateur et diagnostiquer les erreurs courantes.

⚠️ Important avant de commencer

Une installation propre peut supprimer les fichiers et les partitions du disque sélectionné.

Guides disponibles

📋
ÉTAPE 1

1. Préparer l'installation

Vérifier le matériel et protéger les données avant de commencer.

  1. Sauvegardez les documents, photos et autres fichiers importants.
  2. Vérifiez la mémoire RAM, le disque de stockage et l'alimentation.
  3. Vérifiez la compatibilité du PC avec la version de Windows visée.
  4. Préparez une clé USB adaptée et des fichiers d'installation officiels.
  5. Sur un portable, branchez le chargeur pendant l'installation.
🔑
ÉTAPE 2

2. Préparer une clé USB bootable

Créer un support permettant de lancer l'installation.

  1. Utilisez un autre ordinateur fonctionnel et une clé USB de capacité suffisante.
  2. Téléchargez l'outil de création de support ou l'image ISO depuis le site officiel Microsoft.
  3. Suivez les instructions de l'outil.
  4. Attention : la création du support efface généralement le contenu de la clé USB.

Ouvrir le site officiel de téléchargement Windows

⚙️
BIOS / BOOT MENU

3. Démarrer depuis la clé USB

Choisir la clé USB dans le menu de démarrage.

  1. Branchez la clé USB bootable.
  2. Allumez le PC et appuyez plusieurs fois sur la touche de Boot Menu correspondant au modèle.
  3. Sélectionnez l'entrée USB correspondant à votre clé.
  4. Si la clé n'apparaît pas, vérifiez sa création et le port USB.
🪟
ÉTAPE 4

4. Lancer l'installation Windows

Comprendre les premiers écrans de l'installateur.

  1. Choisissez la langue, le format horaire et le clavier.
  2. Cliquez sur Installer maintenant.
  3. Suivez les instructions concernant la licence et l'édition de Windows.
  4. Choisissez le type d'installation en comprenant la différence entre mise à niveau et installation personnalisée.
💽
DISQUE

5. Choisir le disque d'installation

Une étape importante qui peut entraîner une perte de données.

  1. Identifiez le disque cible par sa capacité et les informations affichées.
  2. Ne supprimez aucune partition si vous ne savez pas à quoi elle sert.
  3. Pour une installation propre, confirmez d'abord que les fichiers sont sauvegardés.
  4. En cas de doute, arrêtez-vous et demandez l'aide d'un technicien.
🔄
APRÈS INSTALLATION

6. Terminer et configurer Windows

Effectuer les vérifications après le premier démarrage.

  1. Suivez les étapes de configuration initiale affichées à l'écran.
  2. Connectez-vous au réseau si disponible et vérifiez Windows Update.
  3. Installez les pilotes nécessaires depuis Windows Update ou le site officiel du fabricant.
  4. Vérifiez le son, le réseau, l'affichage, le clavier et les périphériques.
  5. Vérifiez l'activation de Windows avec une licence valide.
🔍
ERREUR

7. Le disque n'apparaît pas

Diagnostic lorsque l'installateur ne trouve aucun disque.

  1. Vérifiez si le disque est détecté dans le BIOS/UEFI.
  2. S'il est absent du BIOS, vérifiez le branchement, le port et le matériel.
  3. S'il est présent dans le BIOS, vérifiez si le contrôleur de stockage nécessite un pilote.
  4. Certains appareils utilisent Intel RST/VMD ou RAID.
  5. Ne formatez pas le disque pour résoudre un problème de détection.
🚫
BOOT

8. Message No Bootable Device

Le PC ne trouve pas de périphérique de démarrage valide.

  1. Vérifiez si le SSD/HDD est détecté dans le BIOS.
  2. Vérifiez l'ordre de démarrage.
  3. Si Windows était installé, essayez les outils de réparation du démarrage.
  4. Si le disque présente des signes de panne, protégez les données.
🛡️
WINDOWS 11

9. Vérifier la compatibilité Windows 11

Windows 11 demande des caractéristiques matérielles spécifiques.

  1. Vérifiez les exigences officielles de processeur, mémoire et stockage.
  2. Windows 11 exige notamment TPM 2.0 et un firmware compatible avec Secure Boot.
  3. Consultez les informations du fabricant avant de modifier les réglages du BIOS.
  4. Ne contournez pas les exigences sans comprendre les risques.

Consulter les exigences officielles de Windows 11
